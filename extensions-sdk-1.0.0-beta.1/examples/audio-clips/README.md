# Audio Clips

Creates audio clips from a file on disk, with control over warp settings and loop points. Demonstrates importing a file into the project and placing it as a clip.

## Setup

Open `src/extension.ts` and change `filePath` to the path of an audio file on your system.

## How to try it

There are two ways to create a clip:

- **Session View:** Right-click an empty clip slot on an audio track and choose **Create unwarped clip** or **Create warped clip**.
- **Arrangement View:** Select a time range on an audio track, right-click, and choose **Create unwarped clip** or **Create warped clip**.
