# Arrangement Selection

Reads the current time selection and selected tracks from the Arrangement View. Demonstrates working with `ArrangementSelection` – including resolving lane handles to typed objects and creating MIDI clips.

## How to try it

In Arrangement View, click and drag to select a time range on a MIDI track, then right-click on that MIDI track and choose **Process selection**. The extension logs the selected beat range and track names, then creates a named MIDI clip on each selected MIDI track or take lane.
