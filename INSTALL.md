## Instructions for using the Packaged Extension. 
1) First, download and install yt-dlp and ffmpeg using the commands in readme
```
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```
2) Go into Ableton
3) Go into your Settings, navigate to Extensions.
4) Verify that Development mode is toggled OFF inside of that page, and drag the ABLX into the box that says drag here, or click on it and select the YoutbeToProject.ablx.
